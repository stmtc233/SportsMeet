分组排道,自动或手动

自动编排只排还没分组的人,可以让同单位的人分开、各组人数均衡。拖动调整后一次保存;已有成绩的组自动锁定,不会被覆盖。

  • 预赛、次赛、半决赛、决赛,各带晋级规则
  • 分道、不分道、分道后抢道
  • 接力与队伍项目按队编排

整场日程一页看清

按天列出每个轮次和每一组的时间。可以把多个轮次连着排,一次定好间隔与预计用时。

  • 同一运动员两组时间重叠或休息不足时提示
  • 接力队员与全能分项一并检查
  • 记录每组实际开赛时间

录完成绩,名次就出来

每次保存后重新计算名次与晋级,并列同名次、下一名顺延。Q 按名次晋级,q 按成绩晋级。

  • 径赛计时、远度逐次、高度逐杆
  • 计次与计分的校园趣味项目
  • 全能按计分表换算积分与总排名

秩序册和成绩册直接打印

选好项目,预览就是纸上的样子。秩序册带竞赛日程表;检录单与成绩记录表按轮次分页。

  • 秩序册、成绩册
  • 检录单,自动算出检录时间
  • 供裁判手写的成绩记录表

报名表一贴就导入

从表格里复制运动员名单粘贴进来,对好列就能导入。运动员属于赛事,各项目共用,号码与学号在赛事内不重复。

  • 35 个常用项目预设,也可自定义
  • 参赛单位可以是学校、班级或代表队

还有这些

数据只在本机

所有数据存在本机的 SQLite 文件里,不上传。升级前自动备份。

让 AI 助手帮忙

开启本机 MCP 后,AI 助手可以查询赛事、导入报名表、编排和录成绩。默认关闭,只接受本机连接;批量改动先预览,确认后才写入。

开放的交换格式

整场赛事可以导出为一个 JSON 文件,再导入到另一台电脑。格式规范是公开的。

操作日志

每次改动都记下时间、来源和内容,出了问题查得到。

浅色与深色

跟随系统外观,也可以手动指定。

不限项目与人数

没有版本之分,所有功能都能用,赛事、项目和运动员数量不设上限。

免费,而且开源

不收费、不用注册、没有广告。
源码以 MIT 协议公开,可以自由使用、修改和分发。
